# STAGE ENGINEER

Веб-приложение для технического специалиста сцены: звук, свет, LED, коммутация, учёт техники.
Работает в браузере телефона, устанавливается на главный экран и после первой загрузки работает без интернета.

**Открыть:** https://bakahentai1.github.io/Stage-ingeneer-/

## Модули

| | Модуль | Статус |
|---|---|---|
| A | Audio Calculator: конфигурация акустики, сабвуферы, мощность усилителей, импеданс, длина и тип кабелей, потери в кабеле, покрытие, SPL, задержка delay-линии | готов |
| B | Генератор схем коммутации: пульт (Qu-16, Qu-24, аналог), стейджбокс или мультикор, Patch List, выходы, список кабелей, схема, питание | готов |
| C | Помощник звукорежиссёра (Qu-16, Qu-24, аналог) | следующий |
| D | Склад техники | в плане |
| E | LED-экраны | в плане |
| F | Свет и DMX | в плане |
| G | Подготовка мероприятия | в плане |

Каждый расчёт показывает формулу, исходные данные, результат, ограничения применимости и предупреждения.
Все расчёты справочные: решения по электропитанию, подвесу и нагрузкам на конструкции принимает квалифицированный специалист.

## Данные

Проекты и расчёты хранятся в IndexedDB на устройстве. В «Настройках» есть резервная копия в JSON-файл и восстановление из него.
Экспорт расчётов: CSV (для Excel: «;», UTF-8 с BOM) и PDF через печать браузера.

## Разработка

```bash
npm install
npm run dev        # локальный сервер
npm test           # автотесты формул и хранилища
npm run build      # сборка в dist/
```

Стек: TypeScript, Preact, Vite, vite-plugin-pwa, idb, Vitest.

```
src/
  calc/       формулы (чистые функции) — у каждой есть тесты в tests/
  wiring/     модуль B: генератор схем (модель, SVG-схема, экспорт)
  core/       хранилище, бэкап, CSV, маршрутизация
  modules/    реестр модулей A–G
  screens/    экраны
  ui/         общие компоненты (карточка расчёта, формы)
```

Публикация: при каждом изменении ветки `main` GitHub Actions прогоняет тесты, собирает приложение и выкладывает его на GitHub Pages.
